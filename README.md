# MapCraft
Interactive Aircraft Progress Map inspired by Air Canada. Available on [akashcraft.ca](https://www.akashcraft.ca/legacy/mapcraft.html).

![image](https://github.com/user-attachments/assets/11af0ec0-28db-4017-9730-c6cc3432eb2f)

## Features
- Informative Side Panel
- 2D Interactive Map
- Settings

## Installation Guide

Download and install the following in order to run the web application:

- VSCode or IntelliJ
- Live Server by Ritwick Dey (Required)

Clone this repository by
```
git clone https://github.com/akashcraft/MapCraft.git
```

If you would like to contribute, then fork this repository instead.

```
git clone <YOUR FORKED REPO ADDRESS> <OPTIONAL FOLDER NAME>
```
